# Actualización: Asistencia, Instrumentos y Control de Notas

1. Publicar las carpetas en la misma raíz de GitHub Pages.
2. En Control de Notas, pulsar Sincronizar estudiantes desde Asistencia. Si los grupos no coinciden, elegir el grupo disponible de la lista. Si el navegador no tiene los datos, utilizar Cargar respaldo de Asistencia con el JSON exportado desde Asistencia.
3. En Instrumentos, seleccionar el mismo grupo y crear instrumentos indicando parcial, actividad, fecha y máximo. Las notas se registran por carnet.
4. En Control de Notas, pulsar Importar notas de Instrumentos por fecha. Los registros con fechas contradictorias o notas existentes distintas se omiten, nunca se sobrescriben.
5. Los datos locales solo se comparten entre páginas del mismo dominio y navegador. GitHub Pages y Firebase Hosting tienen orígenes distintos; para compartir entre dispositivos hace falta sincronización de servidor adicional.
