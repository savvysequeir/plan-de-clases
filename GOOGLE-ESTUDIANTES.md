1. Firebase Authentication > Método de acceso > Google > Habilitar, seleccionar correo de soporte y guardar.
2. Authentication > Configuración > Dominios autorizados: agregar el dominio de GitHub Pages (sin ruta).
3. Respaldar y publicar firebase/firestore.rules en Firestore.
4. Subir todo el portal a GitHub. Abrir asistencia en el navegador que contiene la matrícula local.
5. Estudiante: iniciar con Google, solicitar carnet. Docente: Administración > Cargar solicitudes, verificar identidad y seleccionar grupo exacto, marcar y aprobar. Estudiante: comprobar autorización.
La matrícula se consulta localmente por el docente; no se expone públicamente. La comprobación de identidad es manual. Las cuentas anteriores siguen funcionando. Si hay varios grupos para un carnet, seleccionar el correcto. Prueba primero con una cuenta.
